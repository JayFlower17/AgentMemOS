Quick guide
AgentMemOS observes three things: events come in, memories are formed, traces explain retrieval.
Memory

Structured, reusable task knowledge extracted from agent activity.

Use it to inspect what the system currently remembers.

Scopes define who can see a memory.

agent-local: private scratch for one specific agent.

task-local: shared context inside one task.

team-shared: team-level conclusion or risk useful to multiple agents.

project-global: long-lived knowledge reusable across tasks.

Types define what kind of memory it is.

working: current task state, goal, constraint, or progress.

episodic: concrete event, tool result, finding, failure, or observation.

procedural: reusable practice, rule, workflow, or learned strategy.

Event

Raw agent runtime input, such as a tool result or review finding.

Use it to verify where a memory came from.

Common types: task.created, tool.result.observed, review.finding.created, subtask.completed.

Trace

Audit record for a retrieval request.

Use it to see what was selected, filtered, and why.

Fields: query, agent role, selected memories, filtered memories, reason.

Trace explain panel: click a trace or run Probe. The top shows who retrieved what; the left column shows visible candidates and score parts; the right column shows filtered memories and why they were hidden. The dashboard opens the most informative trace first.
